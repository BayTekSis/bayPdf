# Katkı

[Geliştirme rehberini](docs/DEVELOPMENT.md) izleyin.

Davranış değişikliklerine regresyon testi ekleyin. PHP için Pint/Larastan; UI için build ve Playwright kullanılır. Public build dosyalarını kaynakla birlikte güncelleyin.

Gerçek kişi verisi, .env, vendor, node_modules, SQLite ve özel storage commit edilmez. Yeni dependency'nin uyumluluk, lisans ve maliyetini değerlendirin. API değişikliklerini dokümante edin. Skills için composer sync-ai çalıştırın.
