# BayPdf

Laravel projelerinde belge yerleşimini koddan bağımsız yönetmek için sürümlü PDF şablonları ve görsel tasarımcı.

Geliştirme sürümü; henüz GitHub veya Packagist üzerinde yayımlanmadı.

## Geliştirme

```bash
composer install
composer test
composer sync-ai
```

PHP 8.3+, GD, mbstring ve Laravel 12/13 hedeflenir. Testler Orchestra Testbench ile bağımsız çalışır.

Plan ve durum: [yapilacaklar](yapilacaklar/ROADMAP.md). Mimari: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Lisans henüz seçilmedi; açık kaynak kullanım izni verilmiş değildir.
